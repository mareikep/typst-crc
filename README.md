This repository provides a template for the continuation of a Collaborative Research Centre (CRC) written in the modern typesetting language Typst. 
You can preview the generated proposal PDF file here: [https://mareikep.github.io/typst-crc/proposal.pdf](https://mareikep.github.io/typst-crc/proposal.pdf)

Check the documentation for information about how to update and build the proposal: [https://mareikep.github.io/typst-crc/](https://mareikep.github.io/typst-crc/)
